## Architecture & Capabilities

SentriX combines on-chain ledger activity and real-time gossip network behavior into a single, unified surveillance surface:

1. **Real-Time Monitoring (`MODULE // 01`)**
   - Sub-second mempool ingestion and live peer telemetry.
   - Continuous rescoring loop as new blocks arrive.

2. **Risk Intelligence (`MODULE // 02`)**
   - GraphSAGE inductive graph learning combined with Personalized PageRank (PPR).
   - Dual-signal anomaly reconciliation and automated compliance evidence trails.

3. **Relationship Mapping (`MODULE // 03`)**
   - Force-directed cluster discovery across multi-hop taint propagation.
   - Peel chain unraveling and mixer detection.

4. **Transaction Analytics (`MODULE // 04`)**
   - Historical UTXO flight velocity and temporal timing correlation.
   - Deep forensic drill-down from macro network flows to address-level forensics.

5. **Motion Experience (Alche-Grade)**
   - 3D WebGL encrypted geodesic sphere and interactive particle constellation.
   - Lenis-grade kinetic inertia smooth scrolling.
   - Kinetic rolling slot hover buttons and live scramble text decryption.
   - Interactive Web Audio synthesizer with sound effects.
   - Fullscreen cinematic route transition with mechanical split shutters.

## Quick Start

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
git clone https://github.com/andricmacario/SentriX.git
cd SentriX
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live interface.

### Production Build
```bash
npm run build
npm start
```
